# Branch Logic

The Branch Logic module is responsible for evaluating conditional branch instructions in the RV32I single-cycle processor.

It receives the actual values of `rs1` and `rs2` from the Register File and the branch control information generated by the Decoder. Based on the selected branch operation, it determines whether the branch condition is satisfied.

The module does not calculate the branch target address and does not update the Program Counter. Its responsibility is limited to generating the `branch_taken` signal.

## Supported Instructions

| Instruction | `branch_op_out` | Condition |
|---|---|---|
| `BEQ`  | `3'b000` | `rs1 == rs2` |
| `BNE`  | `3'b001` | `rs1 != rs2` |
| `BLT`  | `3'b100` | Signed `rs1 < rs2` |
| `BGE`  | `3'b101` | Signed `rs1 >= rs2` |
| `BLTU` | `3'b110` | Unsigned `rs1 < rs2` |
| `BGEU` | `3'b111` | Unsigned `rs1 >= rs2` |

The `branch_op_out` values directly correspond to the RISC-V `funct3` encoding used by B-Type instructions.

## Module Interface

```verilog
module BRANCH_LOGIC(
    input wire [31:0] rs1_value,
    input wire [31:0] rs2_value,
    input wire branch_out,
    input wire [2:0] branch_op_out,
    output reg branch_taken
);
